# 关于本站

CUGCS Wiki 是由学生与校友共同维护的非官方开放知识库，服务于中国地质大学（武汉）计算机学习共同体。本站首期覆盖课程学习、竞赛资料、科研经验和保研经验，后续栏目是否扩展由实际内容和共同维护能力决定。

本站参考了 [CS 自学指南](https://csdiy.wiki/) 与 [OI-Wiki](https://oi-wiki.org/) 的公开信息架构和协作方式，但拥有独立的站点身份、内容、样式与许可声明。

## 联系与反馈

发现事实错误、失效链接或不当公开的信息，请通过 [GitHub Issues](https://github.com/CUGCS-Wiki/CUGCS-Wiki.github.io/issues) 反馈。需要修改页面时，可以使用页面右上角的编辑入口提交 Pull Request（拉取请求）。

## 免责声明

本站内容不代表学校、学院、课程教师、竞赛主办方或招生单位的官方立场。涉及课程安排、竞赛规则和招生政策时，请以对应年度的官方通知为准。
