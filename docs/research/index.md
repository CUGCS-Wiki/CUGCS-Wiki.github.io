# 科研经验

科研经验模块记录从“第一次接触科研”到“能够独立推进研究”的方法。重点不是制造成功学，而是把问题形成、证据构建和工程执行的过程讲清楚。

## 初始目录

| 阶段 | 核心问题 | 计划内容 |
| --- | --- | --- |
| 科研入门 | 如何选择方向、导师和第一个问题 | 方向探索、沟通准备、时间预期 |
| 文献调研 | 如何从论文堆里形成问题地图 | 检索、阅读、笔记、证据管理 |
| 问题形成 | 怎样把兴趣变成可验证的科学问题 | 动机、缺口、假设、评价标准 |
| 实验工程 | 如何得到可信、可复现的实验结果 | 环境、版本、日志、消融、误差分析 |
| 学术写作 | 怎样让论证与证据形成闭环 | 叙事、图表、引用、修改流程 |
| 投稿协作 | 如何管理作者协作、审稿和回复 | 分工、版本、审稿意见、复盘 |

!!! note "经验不是规则"
    研究方向、导师风格和项目阶段差异很大。页面应明确作者背景与适用条件；未经验证的推测可以提出，但必须标为推测。

新增页面时，请使用[科研页面模板](page-template.md)。
