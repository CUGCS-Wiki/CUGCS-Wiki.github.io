# 竞赛资料

竞赛资料模块关注完整能力链，而不是单纯堆积报名链接和往届作品。一个可复用的竞赛页面应当回答：为什么参加、需要什么能力、如何组队训练、怎样完成作品，以及赛后如何沉淀。

## 初始目录

| 类别 | 可收录内容 | 重点沉淀 |
| --- | --- | --- |
| 程序设计 | 算法竞赛、程序设计竞赛 | 训练路线、题目复盘、团队协作 |
| 数学建模 | 数学建模与数据分析竞赛 | 建模方法、论文写作、代码组织 |
| 创新创业 | 大学生创新创业类赛事 | 需求验证、项目叙事、答辩准备 |
| 人工智能 | 模型、数据和应用类竞赛 | 评价指标、实验管理、复现方法 |
| 系统与安全 | 系统、网络和安全类赛事 | 环境搭建、工程实现、攻防边界 |
| 综合实践 | 作品赛、设计赛和行业赛 | 选题、原型、展示与长期维护 |

!!! warning "资料边界"
    不上传受保密约束的赛题、测试数据、评审材料或其他队伍的未授权成果。可以分享方法、公开代码和本人团队已同意公开的复盘。

新增页面时，请使用[竞赛页面模板](page-template.md)。
