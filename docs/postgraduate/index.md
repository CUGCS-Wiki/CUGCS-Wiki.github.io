# 保研经验

保研经验模块希望降低信息差，但不会把某一届、某个人的经历包装成固定攻略。招生政策、名额、时间节点和考核形式都可能变化，任何关键决策都应回到当年官方通知。

## 初始目录

| 阶段 | 主要任务 | 应沉淀的信息 |
| --- | --- | --- |
| 前期规划 | 认识规则并建立个人目标 | 时间线、成绩与能力结构、风险点 |
| 院校调研 | 理解方向、导师和培养环境 | 官方项目、研究匹配、信息来源 |
| 材料准备 | 准确呈现经历与能力 | 简历、个人陈述、证明材料、邮件 |
| 夏令营 | 管理申请、考核与选择 | 申请节点、准备范围、面试复盘 |
| 预推免 | 在更短周期内完成决策 | 信息跟踪、并行申请、沟通边界 |
| 最终选择 | 比较方向、导师、平台与生活 | 决策框架、长期目标、确认流程 |

!!! danger "以官方信息为准"
    页面中的政策和时间信息必须附官方来源与核验日期。不要公开个人身份证号、手机号、私人联系方式、未公开名单、群聊截图或内部招生信息。

新增页面时，请使用[经验页面模板](page-template.md)。
