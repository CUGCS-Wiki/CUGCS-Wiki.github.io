# 内容规范

## 先讲清楚页面解决什么问题

页面开头用一两句话说明目标读者、问题和适用范围。不要从资料清单直接开始，也不要把个人经历写成所有人都应遵循的路线。

## 区分三类信息

- 事实：可以由官方通知、课程主页、论文或公开仓库核验。
- 经验：来自作者的实际经历，需要说明背景和限制。
- 推测：用于讨论可能原因或未来选择，必须明确标注为推测。

## 引用与时效

政策、规则、时间、费用、名额、奖项和统计数据必须给出来源与核验日期。优先使用学校、主办方、出版社、论文和项目官方仓库等一手来源。

## 图片、公式与代码

图片应为原创、获授权或符合原始许可，并在图片附近标注来源。实验图应由真实数据生成；公式解释变量含义；代码应能运行或明确标注为伪代码。

## 文件与标题

- 文件名使用简短、稳定的英文小写名称，单词之间使用连字符。
- 一个页面只保留一个一级标题。
- 标题应直接描述内容，避免口号化和夸张表达。
- 链接文字应能说明目标页面，不使用大量“点击这里”。
