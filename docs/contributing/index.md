# 贡献指南

CUGCS Wiki 依靠可核验、可维护的内容长期生长。贡献不要求一次写成完整长文，修正一个事实、补充一个官方链接或澄清一个过时结论，同样有价值。

## 贡献流程

1. 在对应栏目中找到现有页面；如果没有合适位置，先通过 Issue（议题）说明拟新增内容。
2. 复制该栏目的页面模板，用 Markdown 编写内容。
3. 为政策、规则、统计和公开资源添加来源与核验日期。
4. 更新 `mkdocs.yml` 导航，并在本地运行 `mkdocs build --strict`。
5. 提交 Pull Request（拉取请求），说明内容来源、适用范围和主要改动。

## 可以贡献什么

- 对课程定位、知识依赖和学习方法的解释。
- 本人团队有权公开的竞赛训练与复盘。
- 可复用的科研方法、工程流程与失败分析。
- 脱敏后的保研准备经验和官方信息索引。
- 失效链接、错别字、过时信息与排版问题的修复。

## 不能提交什么

- 课程内部题库、未公开试卷和未经授权的作业答案。
- 受竞赛、实验室、实习或合作协议约束的材料。
- 身份证号、手机号、私人邮箱、群聊截图和未公开名单。
- 无法核验却被包装成事实的传闻。
- 从其他网站整段复制、但没有授权和署名的内容。

详细写作要求见[内容规范](style-guide.md)。
