# 课程学习

课程学习模块不只是收集课件和答案，而是解释一门课在培养体系中的位置，以及怎样用有限时间真正掌握它。

## 计划收录的内容

| 内容层次 | 主要问题 | 推荐材料 |
| --- | --- | --- |
| 课程定位 | 这门课解决什么问题，与前后续课程有什么关系 | 课程简介、先修关系、能力目标 |
| 学习路线 | 应该按什么顺序学习，哪些概念是主线 | 周次建议、知识结构、重点难点 |
| 资源选择 | 教材、公开课和工具分别适合什么人 | 官方资料、公开资源、使用说明 |
| 实验实践 | 怎样通过代码和项目建立真实理解 | 实验环境、项目建议、调试经验 |
| 考核复习 | 怎样复习，而不是传播受限题目 | 题型结构、复习方法、常见误区 |

## 初始目录

- 公共基础：数学、物理、英语和通识基础。
- 编程基础：程序设计、数据结构、算法和工程工具。
- 计算机系统：组成原理、操作系统、网络、数据库和编译。
- 人工智能：机器学习、深度学习、计算机视觉、自然语言处理和机器人。
- 实践课程：课程设计、综合实验、项目实训和毕业设计。

新增具体课程时，请从[课程页面模板](page-template.md)复制结构，并把新页面加入 `mkdocs.yml` 导航。
